# hazarkanwah-repo-001

مستودع تجريبي يحتوي واجهة متصفح بسيطة لِـ HAZARKANWAH — Closed 9‑Axis Core.

الملفات المضافة من قِبل المساهم الحالي:

- index.html — واجهة المستخدم الرئيسية (قابلة للفتح مباشرة في المتصفح).
- static/styles.css — أنماط CSS بسيطة.
- static/app.js — منطق النواة والمحورّات وتنفيذ وظائف الواجهة.

ما الذي تم تنفيذه

- نواة محاكاة "CLOSED 9-AXIS CORE" مضمّنة في static/app.js مع محاور AXIS_1..AXIS_9 (قيمة عددية 0-100).
- واجهة تتيح اختيار محور، تعديل قيمته، إعادة تهيئته، توليد قيمة عشوائية.
- عناصر نظام: إعادة النواة، توليد عشوائي لكل المحاور، تطبيق التغييرات (يأخذ لقطة) وتصدير JSON.
- كونسول JSON يعرض الحالة الحالية أو لقطة عند التطبيق، وسجل إجراءات مُدمج.
- كافة الأزرار الواضحة تعمل محليّاً دون خدمات خارجية.

كيفية التشغيل

1. افتح index.html في المتصفح (مثلاً: افتح الملف مباشرة أو استعمل Live Server محلي).
2. جرّب اختيار محور من القائمة، حرّك شريط القيم، ثم اضغط "تعيين".
3. اضغط "تطبيق التغييرات" لمعاينة لقطة الحالة في كونسول JSON.
4. اضغط "تصدير JSON" لتحميل ملف hazarkanwah-core.json.

ملاحظات هندسية

- التصميم مكوّن كحل محلي بحت: لا يحتاج مفاتيح API ولا خدمات مدفوعة.
- تمت المحافظة على الملفات الأصلية (.gitignore, LICENSE, README.md) ولم تُحذف أيّ عمل سابق.
- قرارات آمنة: بما أن تفاصيل "CLOSED 9-AXIS CORE" لم تُعطَ، طوّرت محاكاة تُظهر حالة المحاور وتوفر واجهة برمجية واضحة (methods: set, get, reset, randomize, toJSON).

التطوير المستقبلي المقترح

- ربط الأوامر بعمليات حقيقية إذا توفّرت مواصفات النواة.
- إضافة اختبارات وحدة وسيناريوهات تخيّم (edge cases).
- تحسين واجهة المستخدم (تصميم، ترجمات إضافية، تخزين محلي للتفضيلات).
